# Abstract
This repository includes several tools for learning and deployment of locomotion policies on humanoid and quadrupedal robots.

It includes the retargeting code from the work [Direct Dynamic Retargeting](https://ludovicdematteis.github.io/publication/DDR) from Constant Roux and I along with additional packages for learning and deployment.

The code is closed source for now but should be release upon paper acceptance.
